# Integrative Programming Final Project

## Project Structure

- `SalesSystem/` - Complete sales management system
  - `backend/` - Node.js/Express API server
  - `frontend/` - Main React frontend (donmacchiato)
  - `legacy-frontend/` - Legacy React frontend
- `InventorySystem/` - Inventory management system
  - `backend/` - .NET Core API and WebSocket server
  - `frontend/` - React frontend for inventory

## Setup Instructions

Please follow the REFACTOR_INSTRUCTIONS.md file to restructure the project, then:

1. Navigate to `SalesSystem/backend` and run `npm install`
2. Navigate to `SalesSystem/frontend` and run `npm install`
3. Use the start-servers.bat in SalesSystem folder to start all services
